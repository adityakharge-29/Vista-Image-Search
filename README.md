# Vista

Vista is an image-search app: type a topic, hit Search, and browse matching images in a responsive grid. This is Part 1 — the scaffold and search UI. No fetching yet; the results grid sits empty, waiting for Part 2.

Two design decisions:
1. I used a monochrome near-black palette with a single warm amber accent so images are the only thing competing for attention once results arrive.
2. I placed the category tabs directly under the search bar rather than in a sidebar, so a first-time visitor sees both "type here" and "or try one of these" in the same glance.
